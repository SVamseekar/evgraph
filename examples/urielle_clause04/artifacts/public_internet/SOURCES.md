# What is actually on the internet

Companies do **not** publish filled Clause 4 evidence packs (context register, stakeholder register, AIMS process map). Those sit behind AWS Artifact / Microsoft Service Trust Portal login, or in an auditor’s war room.

What *is* public, and what we used:

| Source | What it really is | Clause 4 use |
| --- | --- | --- |
| [AWS ISO 42001 FAQ](https://aws.amazon.com/compliance/iso-42001-faqs/) | Marketing + certificate pointer; in-scope services named only inside Artifact | 4.3 scope, weakly |
| [AWS AIMS whitepaper PDF](https://d1.awsstatic.com/onedam/marketing-channels/website/aws/en_US/whitepapers/compliance/iso_42001_responsible_management_of_ai_systems.pdf) (May 2026) | Guidance for *customers* building AIMS on AWS, not AWS’s own filled registers | 4.1 / 4.4 language; file we can cite |
| [Microsoft Learn ISO 42001 offering](https://learn.microsoft.com/en-us/compliance/regulatory/offering-iso-42001) | In-scope Copilot/Foundry product list; audit reports behind Service Trust Portal | 4.3 product list; 4.2 customers mentioned, no register |
| [Nexus Financial worked example](https://github.com/Ankit-Uniyal/iso-42001-ai-governance-toolkit/tree/main/14-WORKED-EXAMPLE) | **Fictional** bank, filled scope statement, labelled FICTIONAL | Closest to a real xlsx, still not a live company |

This pack’s responses only cite those public pages/PDFs. They are **not** AWS’s or Microsoft’s confidential AIMS evidence. Running Urielle on them tests “what a questionnaire looks like if someone only has the internet,” which is a real auditor situation.
